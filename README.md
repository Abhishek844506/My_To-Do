# ✅ To-Do List Web App

A simple and interactive **To-Do List Application** built using **HTML, CSS, and JavaScript** that helps users manage daily tasks efficiently.

This application allows users to **add tasks, mark them as completed, delete completed tasks, and automatically save data using Local Storage**, so tasks remain available even after refreshing the browser.

---

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete completed tasks
- 💾 Automatic task saving using **Local Storage**
- 🔄 Tasks remain saved after page refresh
- 📱 Clean and responsive UI
- 🎨 Visual indication for completed tasks

---

- **HTML5** – Structure of the webpage

## ⚙️ How It Works

### 1️⃣ Add a Task
- Type a task in the input field
- Click the **"Add"** button
- Task gets added to the top of the list

### 2️⃣ Complete a Task
- Click the **"Finish"** button
- Task becomes completed with:
  - ✔️ Strikethrough effect
  - 🎨 Background color change
- Completed task moves to the bottom

### 3️⃣ Delete a Task
- Once completed, the **Finish button changes to ❌**
- Click the ❌ button to permanently remove the task

### 4️⃣ Data Persistence
- All tasks are automatically stored in **browser local storage**
- Tasks remain available even after refreshing or reopening the browser
